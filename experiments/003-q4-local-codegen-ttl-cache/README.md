# Q4量子化モデルによるTTLCacheコード生成の評価

対応Issue: [#19](https://github.com/asopitech-labs/asmati-lab/issues/19)

## 問い

Q4量子化のQwen3.8-27Bが、仕様からPythonのTTLCache実装を生成できるかを、実行テストと追加契約テストで確認する。

## 評価方法

温度0、1課題、3回実行のローカル評価。公開受入テスト6件に加え、次の追加契約テスト3件を別プロセスで実行した。

- `clear()`後も累積統計を保持する。
- 同じキーの置換をevictionとして数えない。
- 同じ期限切れ項目を複数回取得してもexpirationを一度だけ数える。

これはHumanEvalやLiveCodeBenchの代替ではなく、単一課題の機能ゲートである。修正を促した生成物は初回成功と混同しない。

## 結果

3回とも公開6件、追加3件、構文検査に合格した。3回の生成物SHA-256は一致し、generationは3.4〜3.5 tok/s、ピークRSSは14.097〜14.142GBだった。

モデル本体、推論ログ、絶対パスを含むローカルログは公開しない。評価用の生成物とテストは [`expected/`](expected/) と [`tests/`](tests/) に置く。
